# lsennn.github.io

The pages of DEUS EX MACHINA, a prompt preset for SillyTavern, Tavo and
Lumiverse. The site opens at https://lsennn.github.io/deus-ex-machina/.

The preset itself, its releases and its README live at
https://github.com/lsennn/Deus-ex-machina.

This repository holds only the published pages. Each commit is one release
of the site. GitHub Pages serves the `main` branch from its root.
